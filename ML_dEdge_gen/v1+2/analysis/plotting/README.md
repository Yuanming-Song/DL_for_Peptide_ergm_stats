# Analysis Scripts for ML_dEdge_gen

This directory contains R scripts for analyzing and visualizing training results from the generative model.

## Available Scripts

### `plot_training_metrics.R`

Plots training curves and metrics from the generative model training.

**Plots generated:**
1. **Training Loss Curves**: Training loss vs validation loss over epochs (all runs combined)
2. **Learning Rate Schedule**: Learning rate over epochs (all runs combined)
3. **Individual Model Plots**: Combined plots for each individual model showing train_loss, valid_loss, and learning_rate
4. **Test Results** (when available):
   - **Predicted dEdge vs True dEdge**: Scatter plot with identity line (red dashed) showing how well generated sequences match target dEdge values
   - **MSE dEdge vs True dEdge**: Mean squared error of dEdge prediction vs target dEdge
   - **Generation Loss vs True dEdge**: Reconstruction loss vs target dEdge
   
   Note: Test results are generated by `run_test_evaluation.py` and saved to `out/{experiment_id}/{run_id}/test_results/test_results_epoch_{epoch}.csv`

**Usage:**
```r
# In R or RStudio
source("plot_training_metrics.R")
```

**Requirements:**
- MLflow output directory must exist at: `ML_dEdge_gen/v1+2/out/`
- Training metrics are automatically logged to MLflow during training
- Test results (if available) are saved in: `out/{experiment_id}/{run_id}/test_results/test_results_epoch_{epoch}.csv`
- Test results are generated by running `run_test_evaluation.py` after training

**Output:**
- Interactive plots using `plotly` (displayed in RStudio/viewer)
- If `saveplt = TRUE`, saves PDF and PNG files to this directory

## Metrics Logged During Training

The training script automatically logs the following metrics to MLflow:

**MLflow Metrics** (logged every epoch):
- `learning_rate`: Current learning rate (after scheduler updates)
- `train_loss`: Training reconstruction loss (cross-entropy)
- `valid_loss`: Validation reconstruction loss (cross-entropy)

**CSV Metrics** (saved to `training_metrics_lr{lr}_bs{bs}_ep{epochs}_{number}.csv`):
- `epoch`: Training epoch number
- `train_loss`: Training reconstruction loss
- `valid_loss`: Validation reconstruction loss
- `learning_rate`: Current learning rate
- `is_best`: Boolean indicating if this epoch had the best validation loss

**Validation Results** (saved when best model is found):
- Saved to: `out/{experiment_id}/{run_id}/validation_results/validation_results_epoch_{epoch}.csv`
- Contains: epoch, true_dEdge, seq_length, n_generated, n_unique, unique_fraction, avg_dEdge_error, avg_predicted_dEdge
- Generated sequences are evaluated using the pre-trained ML_dEdge critic model

These metrics are saved every epoch, allowing real-time monitoring of training progress.
